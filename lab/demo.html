How the copy is made

This is distillation. A large model teaches small models with examples. No real patient data is used at any step.

  1. Gemini writes fake messages

    Portal messages and voicemails, with made-up people. Each one has a different topic, urgency, sender and style.

  2. Gemini answers them

    The Decisions API gives a probability for each answer to four triage questions, and grades messages against staff searches.

  3. Small models learn on Modal

    Gemma 3 1B and EmbeddingGemma learn to give the same probabilities. A GPU in the cloud trains them in minutes.

  4. They run on this computer

    The local server answers the same requests as the Gemini API. It keeps nothing that it reads.

Write down a voicemail

EmbeddingGemma 2 can hear, but it cannot write. A small reader turns what it hears into words, the way eg2.haku.sh does. The test voicemails go through a phone-line effect first.

    What this shows, and what it does not

    It shows

    • The whole path works: real Gemini calls make the labels, Modal trains, and the models answer on this computer.
    • Every score is on test data that the models did not see. Every choice (epoch, model, LM weight) was made on separate val data.
    • The LibriSpeech score is on real human voices.

    It does not show

    • Quality on real clinic messages. All the messages are fake, and the same Gemini writer made train and test.
    • Clinical correctness. The truth is Gemini's answer, not a clinician's.
    • Real phone calls. The test voicemails are TTS voices with a phone-line effect.
    • Small differences in search. The test has only 36 searches.
